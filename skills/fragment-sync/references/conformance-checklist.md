## Model line reference (for B3)

Current tiers per `cl-plugin-structure` model-config (§1 Current Model Line): **Opus 5** (`claude-opus-5`, parallel alias `opus5`) is the new ceiling, rolling out under its own key while **Opus 4.8** (`claude-opus-4-8`) stays pinned to `opus`/`best` as the A/B default **until the alias flip**. So emitted scaffolds keep using the **`model: opus` alias** (which auto-rolls forward at the flip) rather than pinning any Opus ID — **Sonnet 4.6** (`model: sonnet`), **Haiku 4.5** (`model: haiku`); **Fable 5 is enabled but HITL-gated — never a resting default**, so generated scaffolds must **not** emit `claude-fable-5` in template/agent frontmatter (a deliberate, gated escalation, not a routing default). Effort: `low|medium|high|xhigh|max`; **re-baseline routine dispatch toward `medium`** — Opus 5's `low`/`medium` reach what took prior-tier `high`, so keep thinking ON and lower the effort dial for cost rather than dropping to a weaker tier. `[1m]` suffix opens 1M context.
